# v0.12.1 · 周期记账日期可留空

- 周期规则的「每月几号」不再必填。填写 1-28 的规则行为不变：到日首次打开应用自动记一笔，备注带 🔁 标记，同月只记一次。
- 留空的规则永不自动生成流水；「周期记账」列表显示「日期不限 · 到账后点『记一笔』」。
- 点「记一笔」用**当天日期**补记一笔：金额、分类、类型、支付账户沿用规则，收入规则仍固定记「收入」分类、备注带 🔁。
- 同一规则同一自然月只记一次；规则本月已有流水时列表显示「本月已记」（填写日期的规则自动生成后同样显示），删除本月这笔后可以再次补记。
- 数据层用 `dayOfMonth = 0` 表示未指定日期，不新增数据库迁移；完整备份允许 0，旧备份（1-31）行为不变。
