# v0.11.3 · 修复连续保存重复记账

修复「记一笔」界面尚未刷新时，快速连续点保存会产生两条同笔记录、导致账户余额重复扣减的问题。现在同一次保存只写入一条记录。例如账户原有 100 元，记一笔 28 元支出，旧版可能重复记录后显示 44 元；修复后只记录一笔，余额为 72 元。

升级不会自动清理历史重复流水。请先核对已有记录，确认重复后再删除；余额仍与实际不符时，再校准账户余额。
