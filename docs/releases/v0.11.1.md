# v0.11.1 · 金额计算器

记账与编辑表单的金额栏右侧新增计算器入口。打开后，计算器带入当前金额并隐藏系统键盘；金额为空时从0开始。可使用大按键输入连续加、减、乘、除及小数。

按等号可查看表达式和两位小数结果。点右下角“填入”会把结果写入表单金额；它上方的等号只负责计算和预览。填入不会保存流水，仍需使用原有保存操作。关闭计算器会保留原金额。

清空和退格可修正表达式。无效表达式、除零、零或负结果及超过金额上限时会显示中文提示，保留输入并阻止填入。金额仍按原表单规则校验和保存。
