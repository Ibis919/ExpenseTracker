# v0.12.4 · 快捷模板紧凑化 + 长按拖动排序

- 「记一笔」页的「快捷模板」条改为紧凑 chip：只显示分类 emoji + 备注首行（最多 12 字，备注为空时回退分类名），不再显示完整备注与金额，一屏能看到更多模板。
- 「🔁 周期记账」条同样改为「图标 + 备注」紧凑样式：支出取分类 emoji、收入用 💰，已记录的规则仍追加「✓」，点按带入与选中态不变。
- 快捷模板支持长按拖动排序：长按进入拖动（触感反馈），chip 跟手移动、相邻 chip 实时换位（`animateItem` 动画），松手即把新顺序写入数据库 `templates.sortOrder`，下次打开保持。
- 拖动中模板条右侧出现「🗑 删除」落点，拖到该处松手弹出原有「删除模板」二次确认；原来的「长按删除」改为「长按拖动」，删除入口移到该落点。
- 无障碍自定义操作保留：每个模板 chip 仍提供「上移一位 / 下移一位 / 删除」，以及「填入模板」点击语义。
- 数据库 schema 8→9：`templates` 新增 `sortOrder INTEGER NOT NULL DEFAULT 0`（`MIGRATION_8_9`），旧数据按原 id 倒序展示不变；完整备份同步记录 sortOrder，恢复 schema < 9 的旧备份时 sortOrder 记 0。
- 其他页面与行为不变。
