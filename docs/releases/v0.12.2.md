# v0.12.2 · 周期记账快捷条

- 「记一笔」页面新增「🔁 周期记账」快捷条：新增支出或收入时列出已设置的周期规则；没有规则时不显示。
- 每条规则显示备注首行（最多 16 字，备注为空时用分类）、金额（收入带 ＋）和账户（未填写显示「未关联」）；该规则本月已有流水时追加「· 本月已记」。
- 点按即把金额、分类、备注、账户和交易类型带入表单，chip 高亮为选中；带入后仍可改金额，保存后这笔流水挂到该规则，「周期记账」列表随即显示「本月已记」。
- 编辑已有流水时不显示这条快捷条；切换到转账或退款时快捷条隐藏并清空选中的规则，转账与退款不会挂到周期规则上。
- 同一规则同一自然月可以有多笔（例如工资分两次到账）；「本月已记」只是提示，不阻止再保存一笔。周期规则的自动记账与列表「记一笔」仍保持同月只记一次。
- 快捷模板条行为不变：仍只在新增支出时显示。
- 无数据库与备份变更，升级不需要迁移。
