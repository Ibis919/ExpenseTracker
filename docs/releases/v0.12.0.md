# v0.12.0 · 周期记账双向与旧流水补账户

- 周期记账现在分「支出」和「收入」两条规则：新建规则默认支出，升级前已有的规则也按支出处理。收入规则到每月指定日期后，打开应用会自动记一笔收入——备注带 🔁 标记、分类固定「收入」、金额加到规则所选账户余额，不占消费预算与统计。
- 每条周期规则仍只在本月生成一次；改动规则只影响以后生成的流水，已有流水不变。
- v0.10.0 之前的旧流水、CSV 导入的流水补选微信或支付宝时，账户余额保持不变；从未设置过余额的账户仍显示「点击设置」。已经关联账户的流水在微信↔支付宝之间互改，仍按原样影响两边余额。
- 已有退款的原支出仍不能改分类、代付和支付账户，会提示「已有退款，原支出的分类、代付和账户需保持一致」；需要修正时先处理退款记录。
- 升级会保留账本；旧备份（schema 5–7）仍可恢复，其中周期规则默认按支出处理。
