# v0.12.3 · 快捷模板条移到金额上方

- 「记一笔」页面把每天高频使用的「快捷模板」条从表单底部移到金额输入框上方：新增支出时打开即见、无需滚动。
- 「🔁 周期记账」条仍留在表单下部（备注/代付之后、保存区之前），低频入口靠后；两条条因此不再相邻。
- 两条快捷条的显示条件、带入字段、选中态与保存关联全部不变：模板条仍只在新增支出时显示；周期条仍只在新增支出/收入且存在规则时显示，点按带入金额/分类/备注/账户/类型，保存后挂到该规则；编辑已有流水与转账/退款不显示。
- 无数据库与备份变更，升级不需要迁移。
