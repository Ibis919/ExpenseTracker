# v0.11.0 · 清晰账本

采用用户选定的清晰账本布局，保留三个底部页面和本地记账方式。设计优先照顾红绿黄与蓝紫色弱：选中态使用高对比边框和勾号，流水类型、预算状态和图表同时提供文字与符号。

- **F1 保存闭环**：等待入库完成，失败保留输入；新增后返回记录所在月份、清除遮挡记录的筛选并定位。仍可见的编辑保留当前查询。
- **F2 统计修正**：明确比较本月累计与上月整月，缺失分类按零计算；净退款与正负分类使用正确摘要和文字说明。
- **F3 完整备份恢复**：JSON 包含流水、回收站、余额、预算、分类、周期规则与模板。恢复先校验和预览，再确认覆盖；自动保留恢复前保护备份及最近七份每日备份。
- **F4 周期与模板账户**：可绑定微信或支付宝；旧数据保留原有未关联状态。周期规则记录生成月份，移动流水日期或 CSV 覆盖导入不会再次扣款。
- **F5 组合筛选**：关键词与账户、代付状态、日期范围、单笔金额范围可同时使用，支持一键清空。
- **F6 收入、转账与退款**：收入和转账不占预算，双账户转账同步计算；退款关联原支出、继承账户与代付属性，累计退款不可超额，并按退款日期冲减净支出。

账本区分预算剩余与实际账户余额；分类统计继续显示日期、金额和完整备注。九列 CSV 保存交易类型、账户和退款关联，兼容旧版文件。继续使用系统字体和现有依赖。

沿用正式签名，可覆盖安装 v0.6.0 及之后的正式版本。微信/支付宝余额是本地记账余额，不连接支付账户；换机或完整迁移请使用 JSON 备份。
