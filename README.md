# 记账 · ExpenseTracker

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

ExpenseTracker 是一款 Android 原生记账应用，用于记录支出、收入、转账和退款，查看月预算、账户余额与消费统计。账本保存在设备上的本地数据库；应用内更新会连接 CDN 和 GitHub。完整 JSON 与 CSV 文件由用户选择保存或分享，文件离开设备后会受所选保存位置或应用的管理规则影响。

## 安装与更新

- 当前正式版为 **v0.11.3**，支持 **Android 8.0 及以上**。
- [下载最新正式版](https://github.com/Ibis919/ExpenseTracker/releases/latest)，从 Release 页面下载 APK 并按 Android 安装提示操作。首次侧载可能需要允许浏览器或文件管理器「安装未知应用」。
- 已安装正式版可到「账本右上角设置 → 检查更新」，用同一来源的新正式版覆盖升级，通常无需卸载，应用数据会保留。卸载、清除应用数据或恢复出厂设置前，请先将「完整备份」保存到设备之外。
- Android 不允许用签名不同的 APK 覆盖安装。自己构建的开发包可能与正式版签名不同；需要换回正式版时，先导出完整备份，再按系统提示处理安装冲突并从备份恢复。

## 新手起步

1. 在「记一笔」选择支出、收入、转账或退款，填写金额、日期、分类和备注，然后点「保存并返回账本」。
2. 到「账本」点击微信或支付宝余额，设为自己的实际余额；点「账本」右上角的设置按钮，设月预算、管理分类与周期规则。这里是手动维护的账本账户，不会读取支付应用的余额。
3. 首次记账后，到「设置 → 完整备份与恢复 → 保存完整备份」，把 JSON 文件存到设备之外。如何选择备份方式见[备份与换机指南](docs/backup-guide.md)。

## 备份怎么选

| 你的情况 | 建议方式 | 需要知道 |
|---|---|---|
| 日常留档、换手机、重装或清数据前 | 「保存完整备份」，把 JSON 另存电脑、另一设备或网盘 | 保存流水及回收站、账户余额及计算所需数据、预算、分类、模板和周期规则；恢复会覆盖目标账本 |
| 误删一笔 | 先到「设置 → 回收站」恢复 | 保留 30 天；整本恢复会回到备份时的状态 |
| 同一安装中撤销误操作 | 「选择本机备份恢复」 | 每日首次启动生成完整快照，保留最近 7 份；不是实时备份，卸载或清数据会移除这些本机文件 |
| 用表格查看、分享或追加流水 | 「导出 CSV」/「导入 CSV」 | 不含完整设置；合并导入只追加、不去重，重复导入会重复计账 |
| 刚恢复错文件或执行了 CSV 清空导入 | 本机备份列表中的「恢复前的保护备份」 | 只保留最近一次保护状态，下次覆盖操作会替换它 |

完整 JSON、CSV 的具体步骤，以及已有数据、旧版 CSV、恢复失败、双设备迁移等情况，见[备份、恢复与换机指南](docs/backup-guide.md)。

## 功能特性

**记账核心**
- 打开应用直接进入「记一笔」，保存后自动返回明细账本
- 每月支出上限自定义，预算剩余实时派生：`预算剩余 = 预算 − 当月净支出`，与实际支付账户余额分开显示
- 按日共享流水面板，明确显示净支出与代付小计；金额使用系统等宽数字
- 微信、支付宝净支出按月及每天分别显示，并随搜索/筛选结果同步
- 左滑删除（微信同款交互），点击编辑，操作零弹窗
- 超预算用「！超预算」与顶部文字提醒，状态不依赖颜色
- 分类记账，emoji 图标 + 预设常用备注，10 秒记完一笔
- 记账时选择微信或支付宝（默认微信）；明细页点击对应余额可设置当前金额，新记账自动扣减对应账户，编辑、删除、恢复会同步重算
- 升级前的旧流水、周期规则和模板维持未关联账户；新规则和模板可绑定微信或支付宝，代付仍影响实际账户余额
- 保存等待实际写入，失败保留输入；新增后清除搜索、切换到记录月份并定位，仍可见的编辑保留查询条件
- 支持支出、收入、转账、退款：收入和转账不占消费预算，退款关联原支出，按退款发生月份冲减净支出，累计退款不超过原金额
- 金额栏右侧可打开四则计算器：支持连续运算与结果预览，填入后仍由用户手动保存流水

**搜索**
- 明细页顶部搜索框，全库跨月检索
- 自动识别日期 / 备注 / 分类 / 金额关键词，空格分隔多条件同时筛选
- 可与账户、代付状态、日期范围、单笔金额区间组合筛选，一键清空

**统计分析**
- 小环配净支出摘要、单色分类金额条，完整显示分类名称、金额和可用占比；点击查看日期、类型、账户和备注
- 6/12 个月净支出折线趋势，查看月份用空心点标记，提供完整年月和逐月金额文字
- 净退款或正负分类并存时不绘制负数扇区，明确显示占比不适用
- 与明细页月份联动切换

**预算提醒**
- 当月支出达预算 80% / 100% 时发送系统通知，每个门槛每月仅提醒一次

**回收站**
- 左滑删除的记录进入回收站，保留 30 天，随时可恢复
- 设置 → 回收站，逐条恢复或彻底删除，30 天后自动清除

**月度对比**
- 明确比较「本月累计 / 上月整月」，本月尚未结束时说明；缺失分类按零计算，增加/减少同时用箭头、文字和金额

**周期性支出**
- 房租、会员等固定开销登记一次（金额 + 每月几号 + 分类）
- 每月到达日期后打开应用自动记一笔，备注带 🔁 标记，不会重复
- 可编辑周期规则的支付账户，变更仅影响以后生成的流水；独立记录生成月份，移动流水日期或 CSV 覆盖导入后也不会重复生成

**代付记账**
- 帮别人垫付的钱可标记为「代付」：不占预算、不计入统计与超支判定
- 明细列表保留明确「代付」文字，备注写人名即可搜索
- 搜索结果合计自动拆分「我的开销 + 代付」，方便对账催还

**应用内更新**
- 设置页一键检查更新：**国内 CDN（jsDelivr）+ GitHub 双源**
- 发现新版弹窗展示版本号与更新日志，确认后应用内下载（实时进度条），CDN 失败自动回落 GitHub
- 下载完成自动拉起系统安装器覆盖升级，首次需授予「安装未知应用」权限

**数据安全与迁移**
- 完整 JSON 适合换机和完整恢复；CSV 仅交换流水；本机每日备份用于同机误操作后的恢复
- CSV 可分享到微信等应用，也可通过系统保存对话框保存到本机；支持从本机文件选择器或微信等应用「用其他应用打开」导入
- 完整备份、CSV 和本机备份的内容、覆盖范围及操作步骤见[备份与换机指南](docs/backup-guide.md)
- 应用不会自动识别微信或支付宝付款并记账；只记录用户输入的支付方式，也不连接支付账户

**体验细节**
- Material 3 清晰账本蓝灰主题，深色模式跟随系统；只用系统字体，无新增大型依赖
- 针对红绿黄、蓝紫色弱：选中态用高对比边框和勾号，交易与预算用明确文字和正负符号；图表不靠颜色识别
- 表单保存区固定于底部并避让软键盘，大字下关键金额和按钮允许换行
- 金额以「分」存储（Long），无浮点误差

## 技术栈

| 项目 | 选型 |
|---|---|
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 架构 | 单 Activity · MVVM |
| 存储 | Room（本地数据库） |
| 最低支持 | Android 8.0（API 26） |
| 目标版本 | API 34 |

工程不依赖第三方 UI/网络库。

微信、支付宝图形取自 [Simple Icons v16](https://github.com/simple-icons/simple-icons) 的对应品牌图标，品牌归各自权利人所有。本应用只记录支付方式，不连接支付账户。

## 界面结构

底部工具栏三标签 + 设置页：

| 页面 | 内容 |
|---|---|
| 📋 账本 | 预算剩余 · 当前账户余额 · 按日流水 · 搜索与筛选 · 左滑删除 |
| 📊 统计 | 净支出摘要 · 可点分类明细 · 整月比较 · 6/12 月趋势 |
| ➕ 记一笔 | 默认打开 · 四类交易 · 微信/支付宝 · 分类与备注 · 固定保存区 |
| ⚙️ 设置 | 月预算 · 完整备份恢复 · CSV · 周期规则 · 分类 · 回收站 |

## 本地构建

1. Android Studio 打开工程，JDK 21
2. Sync（已配置腾讯云 + 阿里云国内镜像，无需代理）
3. `Build → Build APK(s)` 或命令行：

```bash
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/release/`。配置了 `keystore.properties` 时使用自有签名，否则使用 debug 签名；个人使用可直接侧载安装。

## 本地验证

```bash
./gradlew testDebugUnitTest assembleDebug
```

Windows 使用 `gradlew.bat`。测试通过 Robolectric 运行实际 Room 数据库，覆盖保存失败、余额与净支出、收入/转账/退款、父子删除恢复、数据库迁移、完整备份保护与回滚、周期幂等、组合筛选、新旧 CSV 及退款引用重建；首次运行需下载测试依赖。另在 SDK 34 原生渲染环境验收真实 Compose 保存流程、统计、深色模式和 200% 字体的关键控件边界，截图输出到 `app/build/reports/native-ui/`。这些自动检查不替代真机键盘与无障碍朗读验收。
