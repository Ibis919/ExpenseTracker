# 记账 · ExpenseTracker

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一款 Android 原生记账应用：定预算、记流水、看统计，专注「这个月还能花多少」这一件事。纯本地存储，数据不出设备（仅在检查更新时访问 GitHub）。

## 功能特性

**记账核心**
- 打开应用直接进入「记一笔」，保存后自动返回明细账本
- 每月支出上限自定义，预算剩余实时派生：`预算剩余 = 预算 − 当月净支出`，与实际支付账户余额分开显示
- 按日共享流水面板，明确显示净支出与代付小计；金额使用系统等宽数字
- 左滑删除（微信同款交互），点击编辑，操作零弹窗
- 超预算用「！超预算」与顶部文字提醒，状态不依赖颜色
- 分类记账，emoji 图标 + 预设常用备注，10 秒记完一笔
- 记账时选择微信或支付宝（默认微信）；明细页点击对应余额可设置当前金额，新记账自动扣减对应账户，编辑、删除、恢复会同步重算
- 升级前的旧流水、周期规则和模板维持未关联账户；新规则和模板可绑定微信或支付宝，代付仍影响实际账户余额
- 保存等待实际写入，失败保留输入；新增后清除搜索、切换到记录月份并定位，仍可见的编辑保留查询条件
- 支持支出、收入、转账、退款：收入和转账不占消费预算，退款关联原支出，按退款发生月份冲减净支出，累计退款不超过原金额

**搜索**
- 明细页顶部搜索框，全库跨月检索
- 自动识别日期 / 备注 / 分类 / 金额关键词，空格分隔多条件同时筛选
- 可与账户、代付状态、日期范围、单笔金额区间组合筛选，一键清空

**统计分析**
- 小环配净支出摘要、单色分类金额条，完整显示分类名称、金额和可用占比；点击查看日期、类型、账户和备注
- 6/12 个月净支出折线趋势，查看月份用空心点标记，提供完整年月和逐月金额文字
- 净退款或正负分类并存时不绘制负数扇区，明确显示占比不适用
- 与明细页月份联动切换

**预算提醒**
- 当月支出达预算 80% / 100% 时发送系统通知，每个门槛每月仅提醒一次

**回收站**
- 左滑删除的记录进入回收站，保留 30 天，随时可恢复
- 设置 → 回收站，逐条恢复或彻底删除，30 天后自动清除

**月度对比**
- 明确比较「本月累计 / 上月整月」，本月尚未结束时说明；缺失分类按零计算，增加/减少同时用箭头、文字和金额

**周期性支出**
- 房租、会员等固定开销登记一次（金额 + 每月几号 + 分类）
- 每月到达日期后打开应用自动记一笔，备注带 🔁 标记，不会重复
- 可编辑周期规则的支付账户，变更仅影响以后生成的流水；独立记录生成月份，移动流水日期或 CSV 覆盖导入后也不会重复生成

**代付记账**
- 帮别人垫付的钱可标记为「代付」：不占预算、不计入统计与超支判定
- 明细列表保留明确「代付」文字，备注写人名即可搜索
- 搜索结果合计自动拆分「我的开销 + 代付」，方便对账催还

**应用内更新**
- 设置页一键检查更新：**国内 CDN（jsDelivr）+ GitHub 双源**，不开 VPN 也能用
- 发现新版弹窗展示版本号与更新日志，确认后应用内下载（实时进度条），CDN 失败自动回落 GitHub
- 下载完成自动拉起系统安装器覆盖升级，首次需授予「安装未知应用」权限
- 仅在检查更新时联网，记账数据全程不出设备

**数据安全**
- CSV 导出双通道：分享到微信等应用 / 系统保存对话框存本机
- CSV 导入双通道：本机文件选择器 + 微信等应用内「用其他应用打开」直达导入
- 九列 CSV 包含支付账户和四类交易，退款通过文件内序号重建关联，兼容旧版 3–6 列文件
- CSV 只交换流水，不保存余额、预算与规则；覆盖导入前保存完整保护备份，失败事务回滚
- 完整 JSON 备份包含流水、回收站、账户余额、预算、分类、模板、周期规则及生成状态；换机请使用完整备份
- 文件恢复与本机备份恢复先校验并展示摘要，确认后覆盖，恢复前自动保护当前数据；损坏或未来格式不能覆盖
- 每日首次启动保存完整备份，保留最近 7 份；旧版内部数据库快照保留，恢复入口使用新的完整 JSON 格式

**体验细节**
- Material 3 清晰账本蓝灰主题，深色模式跟随系统；只用系统字体，无新增大型依赖
- 针对红绿黄、蓝紫色弱：选中态用高对比边框和勾号，交易与预算用明确文字和正负符号；图表不靠颜色识别
- 表单保存区固定于底部并避让软键盘，大字下关键金额和按钮允许换行
- 金额以「分」存储（Long），无浮点误差

## 技术栈

| 项目 | 选型 |
|---|---|
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 架构 | 单 Activity · MVVM |
| 存储 | Room（本地数据库） |
| 最低支持 | Android 8.0（API 26） |
| 目标版本 | API 34 |

工程不依赖第三方 UI/网络库。

微信、支付宝图形取自 [Simple Icons v16](https://github.com/simple-icons/simple-icons) 的对应品牌图标，品牌归各自权利人所有。本应用只记录支付方式，不连接支付账户。

## 界面结构

底部工具栏三标签 + 设置页：

| 页面 | 内容 |
|---|---|
| 📋 账本 | 预算剩余 · 当前账户余额 · 按日流水 · 搜索与筛选 · 左滑删除 |
| 📊 统计 | 净支出摘要 · 可点分类明细 · 整月比较 · 6/12 月趋势 |
| ➕ 记一笔 | 默认打开 · 四类交易 · 微信/支付宝 · 分类与备注 · 固定保存区 |
| ⚙️ 设置 | 月预算 · 完整备份恢复 · CSV · 周期规则 · 分类 · 回收站 |

## 本地构建

1. Android Studio 打开工程，JDK 21
2. Sync（已配置腾讯云 + 阿里云国内镜像，无需代理）
3. `Build → Build APK(s)` 或命令行：

```bash
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/release/`。配置了 `keystore.properties` 时使用自有签名，否则使用 debug 签名；个人使用可直接侧载安装。

## 本地验证

```bash
./gradlew testDebugUnitTest assembleDebug
```

Windows 使用 `gradlew.bat`。测试通过 Robolectric 运行实际 Room 数据库，覆盖保存失败、余额与净支出、收入/转账/退款、父子删除恢复、数据库迁移、完整备份保护与回滚、周期幂等、组合筛选、新旧 CSV 及退款引用重建；首次运行需下载测试依赖。另在 SDK 34 原生渲染环境验收真实 Compose 保存流程、统计、深色模式和 200% 字体的关键控件边界，截图输出到 `app/build/reports/native-ui/`。这些自动检查不替代真机键盘与无障碍朗读验收。
