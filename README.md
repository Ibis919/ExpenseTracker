# 记账 · ExpenseTracker

一款 Android 原生记账应用：定预算、记流水、看统计，专注「这个月还能花多少」这一件事。纯本地存储，**零联网权限**，数据只属于你。

## 功能特性

**记账核心**
- 每月支出上限自定义，余额实时派生：`余额 = 预算 − 当月累计支出`
- 按日分组展示流水，每笔独立卡片，当日小计一目了然
- 左滑删除（微信同款交互），点击编辑，操作零弹窗
- 支出超出预算后，从超支那笔起整行标红 + 顶部「已超支」提醒
- 分类记账，emoji 图标 + 预设常用备注，10 秒记完一笔

**统计分析**
- 环形图展示当月分类占比，中心显示总支出
- 近 6 个月支出柱状趋势，当月高亮
- 与明细页月份联动切换

**预算提醒**
- 当月支出达预算 80% / 100% 时发送系统通知，每个门槛每月仅提醒一次

**数据安全**
- CSV 导出（带 BOM 的 UTF-8，Excel 直接打开不乱码），系统分享面板一键发送
- CSV 导入，支持「合并追加」与「清空重建」两种策略，换机迁移闭环
- 每日首次启动自动备份数据库，保留最近 7 份

**体验细节**
- Material 3 + 动态取色，深色模式自动跟随系统
- 列表动画、页面切换动画、余额渐变卡片
- 金额以「分」存储（Long），无浮点误差

## 技术栈

| 项目 | 选型 |
|---|---|
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 架构 | 单 Activity · MVVM |
| 存储 | Room（本地数据库） |
| 最低支持 | Android 8.0（API 26） |
| 目标版本 | API 34 |

全工程 12 个 Kotlin 源文件，无第三方 UI/网络库，依赖干净。

## 界面结构

底部工具栏三标签 + 设置页：

| 页面 | 内容 |
|---|---|
| 📋 明细 | 余额卡片 · 预算进度条 · 按日分组流水 · 左滑删除 |
| 📊 统计 | 分类环形图 · 分类图例 · 近 6 个月柱状趋势 |
| ➕ 记一笔 | 大金额键盘 · 分类选择 · 常用备注 |
| ⚙️ 设置 | 月度预算 · CSV 导出/导入 · 备份状态 |

## 本地构建

1. Android Studio 打开工程，JDK 21
2. Sync（已配置腾讯云 + 阿里云国内镜像，无需代理）
3. `Build → Build APK(s)` 或命令行：

```bash
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/release/`，debug 签名，可直接侧载安装，个人使用无需上架应用商店。
