# 记账 · ExpenseTracker

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一款 Android 原生记账应用：定预算、记流水、看统计，专注「这个月还能花多少」这一件事。纯本地存储，数据不出设备（仅在检查更新时访问 GitHub）。

## 功能特性

**记账核心**
- 每月支出上限自定义，余额实时派生：`余额 = 预算 − 当月累计支出`
- 按日分组展示流水，每笔独立卡片，当日小计一目了然
- 左滑删除（微信同款交互），点击编辑，操作零弹窗
- 支出超出预算后，从超支那笔起整行标红 + 顶部「已超支」提醒
- 分类记账，emoji 图标 + 预设常用备注，10 秒记完一笔

**搜索**
- 明细页顶部搜索框，全库跨月检索
- 自动识别日期 / 备注 / 分类 / 金额关键词，空格分隔多条件同时筛选

**统计分析**
- 环形图展示当月分类占比，中心显示总支出
- 近 6 个月支出柱状趋势，当月高亮
- 与明细页月份联动切换

**预算提醒**
- 当月支出达预算 80% / 100% 时发送系统通知，每个门槛每月仅提醒一次

**回收站**
- 左滑删除的记录进入回收站，保留 30 天，随时可恢复
- 设置 → 回收站，逐条恢复或彻底删除，30 天后自动清除

**月度对比**
- 统计页「本月 vs 上月」环比卡片：总支出涨跌百分比 + 变化最大的三个分类

**周期性支出**
- 房租、会员等固定开销登记一次（金额 + 每月几号 + 分类）
- 每月到达日期后打开应用自动记一笔，备注带 🔁 标记，不会重复

**代付记账**
- 帮别人垫付的钱可标记为「代付」：不占预算、不计入统计与超支判定
- 明细列表照常显示（橙色「代付」标签），备注写人名，一搜即知数额
- 搜索结果合计自动拆分「我的开销 + 代付」，方便对账催还

**应用内更新**
- 设置页一键检查更新：**国内 CDN（jsDelivr）+ GitHub 双源**，不开 VPN 也能用
- 发现新版弹窗展示版本号与更新日志，确认后应用内下载（实时进度条），CDN 失败自动回落 GitHub
- 下载完成自动拉起系统安装器覆盖升级，首次需授予「安装未知应用」权限
- 仅在检查更新时联网，记账数据全程不出设备

**数据安全**
- CSV 导出双通道：分享到微信等应用 / 系统保存对话框存本机
- CSV 导入双通道：本机文件选择器 + 微信等应用内「用其他应用打开」直达导入
- 支持「合并追加」与「清空重建」两种导入策略，换机迁移闭环
- 每日首次启动自动备份数据库，保留最近 7 份

**体验细节**
- Material 3 + 动态取色，深色模式自动跟随系统
- 列表动画、页面切换动画、余额渐变卡片
- 金额以「分」存储（Long），无浮点误差

## 技术栈

| 项目 | 选型 |
|---|---|
| 语言 | Kotlin |
| UI | Jetpack Compose + Material 3 |
| 架构 | 单 Activity · MVVM |
| 存储 | Room（本地数据库） |
| 最低支持 | Android 8.0（API 26） |
| 目标版本 | API 34 |

全工程 12 个 Kotlin 源文件，无第三方 UI/网络库，依赖干净。

## 界面结构

底部工具栏三标签 + 设置页：

| 页面 | 内容 |
|---|---|
| 📋 明细 | 余额卡片 · 预算进度条 · 按日分组流水 · 左滑删除 |
| 📊 统计 | 分类环形图 · 分类图例 · 近 6 个月柱状趋势 |
| ➕ 记一笔 | 大金额键盘 · 分类选择 · 常用备注 |
| ⚙️ 设置 | 月度预算 · CSV 导出/导入 · 备份状态 |

## 本地构建

1. Android Studio 打开工程，JDK 21
2. Sync（已配置腾讯云 + 阿里云国内镜像，无需代理）
3. `Build → Build APK(s)` 或命令行：

```bash
./gradlew assembleRelease
```

产物位于 `app/build/outputs/apk/release/`，debug 签名，可直接侧载安装，个人使用无需上架应用商店。
